# LOSCAM 待客户确认问题总表

## 1. 这份文档的目的
这份文档用于把当前 LOSCAM 项目中还需要客户确认的问题统一收口。

它覆盖：
- 业务模式
- 节点与流程
- 状态口径
- 数据可得性
- 需求预测
- 优化调拨
- 运输执行
- 系统边界
- MVP 范围
- 试点验收

建议使用方式：
- 拿这份清单逐项和客户确认
- 每个问题记录：已确认 / 待确认 / 不适用 / 后续阶段
- 对于影响范围和报价的问题，单独标记

---

## 2. 确认状态建议
建议在实际使用时，每个问题后面增加状态：

```text
状态：未确认 / 已确认 / 待客户补资料 / 后续阶段 / 不适用
负责人：
客户回复：
影响模块：
备注：
```

# Part 1. 业务模式确认

## 3. 托盘池化业务模式
### 3.1 需要确认的问题
1. LOSCAM 当前试点范围内的托盘是统一池化管理，还是分区域 / 分客户管理？

# Part 16. 使用建议

## 18. 建议怎么推进确认
### 18.1 第一轮
先确认：
- 业务目标
- 试点范围
- 节点结构
- 状态口径

### 18.2 第二轮
再确认：
- 数据来源
- 数据质量
- 需求口径
- soon available / inbound 口径

### 18.3 第三轮
最后确认：
- 优化规则
- 运输约束
- 审批流程
- 验收标准

这样问，逻辑会比较顺，不会一开始就陷入算法细节。
