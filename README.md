## 范围说明

本发布仓库只保留当前成熟文档集。
草稿、工作笔记、日志以及 GitBook API 探测脚本均已刻意排除，以确保对外阅读路径更聚焦、更安全。

## 系统定位

LC 当前定位为一个围绕托盘池化业务的决策支持系统，核心关注点包括：

- 缺口识别
- 需求预测
- 调拨建议
- 人工审批
- 执行反馈

本仓库的目标不是描述一个大而全的平台，而是支撑一个可控的 MVP 评审与实施路径。
